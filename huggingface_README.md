# Smartwatch Heart-Rate Analyzer

Upload an exported smartwatch heart-rate CSV (for example Fitbit
`heartrate_seconds_merged.csv`), optionally with Fitbit activity, steps and
sleep files. You get cleaned data, charts, activity- and sleep-aware
statistics, unusual-pattern detection and a plain-language PDF report.

Informational only. Not a medical device and not a diagnosis.
